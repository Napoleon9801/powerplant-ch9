1. Smart Grid Overview โครงข่ายไฟฟ้าอัจฉริยะ

นิยาม Smart Grid

Smart Grid = Power Grid + Communication/Computer Technology

ระบบที่ช่วยตัวเองได้ (self-sufficient) รองรับแหล่งผลิตไฟฟ้าทุกขนาดและทุกประเภท มุ่งสู่ความยั่งยืน (sustainable), ความน่าเชื่อถือ (reliable), ความปลอดภัย (safe) และคุณภาพพลังงาน (quality electricity)

เป้าหมายหลัก — 5 Grid Improvements

  1. Real-time Simulation — จำลองสถานการณ์แบบเรียลไทม์
  2. Wide-Area Reliability — ความน่าเชื่อถือในพื้นที่กว้าง
  3. Network Optimization — ปรับปรุงประสิทธิภาพโครงข่าย
  4. Customer Participation — เปิดให้ผู้ใช้ไฟมีส่วนร่วม
  5. Participation in Energy Markets — เชื่อมกับตลาดพลังงาน

3 เสาหลักของ Smart Grid

  1. Digital Technology — AI, IoT
  2. Sensor System — IED, Smart Meter, PMU
  3. Automated Control System — SCADA, EMS, DMS

ทั้ง 3 เสาเชื่อมกันด้วย Communication Network Backbone

Grid Evolution — Centralized → Distributed

ระบบไฟฟ้าดั้งเดิมเป็น Centralized (ผลิตจาก Power Plant ขนาดใหญ่)

Smart Grid รองรับ Distributed Energy Resources (DERs):

  • V2G (Vehicle-to-Grid) — รถยนต์ไฟฟ้าส่งพลังงานกลับสู่กริด
  • Demand Management — บริหารความต้องการไฟ
  • Microgrid — ระบบไฟฟ้าขนาดเล็กที่ดูแลตัวเองได้
  • Virtual Power Plant — รวม DER หลายจุดเป็นโรงไฟฟ้าเสมือน
  • Bi-directional Power Flow — ไฟไหลได้สองทิศทาง

3. SCADA · EMS · DAS

SCADA — Supervisory Control and Data Acquisition

ระบบควบคุมและตรวจสอบระบบไฟฟ้าจากระยะไกล ประกอบด้วย 4 องค์ประกอบหลัก:

  1. การควบคุมจากระยะไกล (Remote Control)
  2. การตรวจสอบแบบเรียลไทม์ (Real-time Monitoring)
  3. การเก็บและวิเคราะห์ข้อมูล (Data Acquisition & Analysis)
  4. การแสดงผลผ่าน HMI (Human-Machine Interface)

ข้อดีของ SCADA

  • Distributed Architecture — ควบคุมจากศูนย์กลาง
  • ลดความผิดพลาดจากมนุษย์
  • การสื่อสารแบบดิจิทัล (Digital Communication)

EMS — Energy Management System

ระบบบริหารพลังงานระดับสูง ใช้งานร่วมกับ SCADA:

  • Load Forecast — พยากรณ์ความต้องการใช้ไฟ
  • Economic Dispatch — จ่ายโหลดประหยัดที่สุด
  • AGC (Automatic Generation Control) — ควบคุมความถี่อัตโนมัติ
  • Optimal Power Flow (OPF) — กระแสไหลที่เหมาะสมที่สุด
  • Security Monitoring — ตรวจสอบความมั่นคง

DAS — Distribution Automation System

  • Smart Switch อัตโนมัติ
  • Phasor Measurement Units (PMU)
  • Two-way SCADA Communication
  • ใช้กับระบบจำหน่าย (Distribution Level)

4. การสื่อสารใน Smart Grid Communication

Topology ใน Substation

Star Topology

อุปกรณ์ทุกตัวเชื่อมตรงสู่ศูนย์กลาง (Hub/Switch)

ข้อดี: ง่ายต่อการจัดการ, แยกปัญหาได้ง่าย

ข้อเสีย: หากศูนย์กลางเสีย ระบบหยุด

Ring Topology

อุปกรณ์เชื่อมต่อเป็นวงแหวน

ข้อดี: Redundancy สูง, หากสาย 1 เส้นขาดยังทำงานได้

ใช้ใน: IEC 61850 Protection & Control

ประโยชน์ของ Communication Network ใน Substation

  • Enhanced Communication Stability
  • Real-time Control & Monitoring
  • Reduced Data Loss
  • Foundation for Protection & Control (IEC 61850)

ตัวอย่าง: Differential Protection ผ่าน Communication

Relay ทั้งสองด้านสื่อสารกันผ่าน Channel เพื่อเปรียบเทียบกระแส:

ΔV = VT₁ − VT₂ // ถ้า ΔV ≠ 0 → Fault detected

IED Differential Relay ที่ปลายแต่ละด้านตรวจจับ Fault และส่งคำสั่ง Trip

5 ขั้นตอนการส่งสัญญาณ/ข้อมูลใน SCADA

  1. Signal Conversion — CT/VT → Analog → Digital ผ่าน RTU/IED
  2. Encoding & Framing — Modbus, DNP3, IEC 60870-5-104, IEC 61850
  3. Transmission — LAN, Fiber Optic, Wireless, PLC (Serial หรือ Packet-based)
  4. Error Checking & Acknowledgement — CRC, Parity Bit; ACK/NACK
  5. Processing & Visualization — HMI Workstation

5.1 Power Line Carrier (PLC)

ใช้สายส่งไฟฟ้าเป็นตัวกลางในการสื่อสาร ใช้สัญญาณความถี่สูง 30–500 kHz ซ้อนทับบน AC Power

องค์ประกอบ PLC

  • Line Matching Unit (LMU) — คู่สัญญาณเข้าสาย
  • Coupling Capacitor — ส่งผ่านความถี่สูง บล็อก AC 50 Hz
  • Line Trap — วงจร LC resonant, Z → ∞ ที่ความถี่ resonant ป้องกันสัญญาณรั่วเข้าสายอื่น
  • Coaxial Cable — เชื่อมต่ออุปกรณ์ภายในสถานี

สูตร Line Trap

ZLT = ZL ‖ ZC (parallel resonant) ที่ resonant frequency: ZLT → ∞ // สัญญาณถูก block ไม่ผ่านเข้า substation อื่น C = 1 / ((2πf)² × L)

ตัวอย่าง

f = 100 kHz, L = 0.25 mH C = 1 / ((2π × 100×10³)² × 0.25×10⁻³) C = 1 / (3.948×10¹¹ × 2.5×10⁻⁴) C ≈ 10.14 nF

5.3 Coaxial Cable

สาย Copper ชั้นใน + Outer Conductor Shield + Outer Jacket

  • ลด Radiation Loss และ Skin Effect
  • ป้องกัน Electromagnetic Interference
  • ความเร็วสูงสุด ~10 Mbps ที่ระยะหลายร้อยเมตร
  • ใช้เชื่อม PLC Coupler ภายใน Substation
5.4 Optical Fiber

สัญญาณแสง ความเร็วสูงมาก ไม่ถูก EMI รบกวน เหมาะมากสำหรับ Substation

3 รูปแบบในระบบไฟฟ้า

  • OPGW (Optical Ground Wire) — Fiber ฝังในสาย Shield/Ground Wire บน Tower
  • Phase Conductor Wrapping — ม้วนบนสายเฟส
  • ADSS (All-Dielectric Self-Supporting) — ไม่มีโลหะ รับน้ำหนักตัวเอง

โครงสร้าง OPGW

Stainless Steel Tube + Optic Fiber + Aluminum Cladding Steel Wire

ติดตั้งด้วย: Tension Assembly, Vibration Damper, Suspension Assembly, Joint Box, FDH (Fiber Distribution Hub)

5.6 Satellite Communication

GEO (Geostationary)

  • Altitude: 35,786 km
  • Latency: >500 ms
  • ครอบคลุม ~1/3 ของโลก
  • ใช้ใน SCADA ห่างไกลมาก

  • Latency: <50 ms
  • รองรับ TCP/IP
  • Weather resilience สูงกว่า GEO

IPv4 vs IPv6

IPv4

  • 32-bit address, 4 octets (0–255)
  • Max 4.3 billion addresses
  • Class A/B/C/D/E classification
  • ตัวอย่าง: 192.168.0.1
  • ไม่เพียงพอสำหรับ IoT

IPv6

  • 128-bit hexadecimal (8 groups × 4 hex)
  • 3.4 × 10³⁸ addresses
  • Auto-configuration, IPsec built-in
  • Improved routing efficiency
  • แก้ปัญหา IoT address shortage

8. Modbus Protocol

Modbus = โปรโตคอลสื่อสารระดับ Application Layer พัฒนาโดย Modicon (Schneider Electric) ปี 1979

ใช้แพร่หลายใน SCADA, PLC, RTU, IED, Sensors/Actuators ด้วยความเรียบง่าย (Simple) และเป็น Open Protocol

9. DNP3 Protocol

DNP3 (Distributed Network Protocol) = โปรโตคอล SCADA สำหรับระบบไฟฟ้าโดยเฉพาะ

พัฒนาโดย Westronic (1993) → ปัจจุบันดูแลโดย DNP Users Group → IEEE Standard: IEEE 1815-2010

กฟภ. (PEA) และ กฟน. (MEA) ใช้ DNP3 เป็น Protocol หลักในระบบ SCADA ระดับสถานีไฟฟ้า

Architecture: Master–Outstation

SCADA TermDNP3 Term
MasterControl Center
SlaveOutstation (RTU)

จุดเด่นของ DNP3

Outstation สามารถส่ง Event ได้เอง — ไม่ต้องรอ Master poll

ลด Communication Traffic, SCADA รับข้อมูลเร็วกว่า Polling

DNP3 Frame Structure

DNP3 vs Modbus — ข้อสรุป

Modbus = Polling Only

DNP3 = Polling + Event Reporting + Timestamp + Security (DNP3-SA)

DNP3 คือหัวใจของ Modern Remote SCADA

10. IEC 61850

IEC 61850 ไม่ใช่แค่โปรโตคอล แต่เป็น มาตรฐานระบบสถานีไฟฟ้า ครบถ้วน

ใช้ Ethernet-based Communication เป็นหลัก, Object-oriented Data Model, รองรับ High-speed Protection Messaging

ทำให้อุปกรณ์จากต่าง Vendor ทำงานร่วมกันได้ (Interoperability) — Function-based Standard

Data Structure — 4 ระดับ

  1. Physical Device (IED) — อุปกรณ์จริงพร้อม Network IP Address
  2. Logical Device (LD) — กลุ่มฟังก์ชัน: Measurements, Protection, Monitoring, Recording
  3. Logical Node (LN) — ฟังก์ชันย่อย: Measurement, Protection functions, Supervisory control
  4. Data Object / Data Attribute — ค่าจริง: Measurands, Settings, Status information, Controllable data

13. Substation Interlocking & SBO

Substation Interlocking (ระบบอินเตอร์ล็อกกิ้ง)

ระบบที่ ป้องกันไม่ให้สั่งการอุปกรณ์ผิดลำดับ เช่น เบรกเกอร์หรือสวิตช์ผิดตำแหน่ง

  • ไม่ให้เกิดการจ่ายไฟย้อนทิศทางกลับสู่แหล่งจ่ายชุดอื่น
  • ไม่ให้สวิตช์ต่อลงดินในจุดที่ยังมีการจ่ายไฟค้างอยู่ (เกิดลัดวงจรลงดิน)
  • ไม่ให้สวิตช์ DS ปิดวงจรต่อมีโหลด (Arc Flash)

ใช้ GOOSE ผ่าน IEC 61850 สำหรับ Interlocking ความเร็วสูง (<4 ms)

เงื่อนไข Interlocking สำหรับการปิด CB

  1. Earthing Switch ต้องอยู่ในตำแหน่ง OPEN
  2. Isolator ต้องอยู่ในตำแหน่ง CLOSE
  3. จึงจะ CB ได้รับอนุญาตให้ปิดวงจร (CLOSE)

SBO — Select Before Operate

SBO = "หลักการสั่งงานสองจังหวะ" เพื่อป้องกันการสั่งผิดอุปกรณ์ในสถานีไฟฟ้าแรงสูง

เป็นมาตรฐาน Safety Barrier ในระบบ SCADA/BCU/RTU ของสถานีไฟฟ้าแรงสูงทั่วโลก

ขั้นตอน SBO

Step 1: SELECT

  1. ผู้ปฏิบัติงานเลือกอุปกรณ์ (เช่น Breaker 52-A)
  2. ระบบตรวจสอบ Interlocking Logic ทั้งหมด
  3. ถ้าผ่าน → "Selected OK" + เปิด Time Window (10–30 วินาที)
  4. ถ้าไม่ผ่าน → ปฏิเสธทันที

Step 2: OPERATE

  1. ผู้ปฏิบัติงานกดคำสั่ง (OPEN/CLOSE)
  2. ระบบตรวจสอบ Interlock อีกครั้ง (Double Check)
  3. ส่งคำสั่งไปยัง BCU/RTU → อุปกรณ์จริง
  4. ระบบยืนยันผลลัพธ์ (Command Execution Feedback)

Timeout

ถ้าไม่กด Operate ภายใน 10–30 วินาที → ต้อง Select ใหม่ → ป้องกันการสั่งงานโดยไม่ตั้งใจ

ทำไมต้องมี SBO?

สถานีไฟฟ้าแรงสูงมีความเสี่ยงสูง:

  • อุปกรณ์มีจำนวนมาก, หน้าจอ SCADA มีหลาย Bay
  • ความผิดพลาดเพียงคลิกเดียวอาจทำให้เกิด Blackout หรืออุบัติเหตุร้ายแรง

SBO ช่วยลด Human Error:

  • ลดความเสี่ยงการคลิกผิด (ต้อง "เลือกก่อน → สั่งทีหลัง")
  • บังคับผู้ปฏิบัติงานตรวจสอบชื่ออุปกรณ์
  • ระบบตรวจสอบ Interlock ก่อนส่งคำสั่ง
  • ป้องกัน Double Command (Timeout ป้องกัน)
  • ป้องกันการสั่งงานโดยไม่ตั้งใจ

ถ้าไม่มี SBO — ผลที่ตามมา

  • Mis-operation: ตั้งใจเปิด 52-A แต่เผลอคลิก 52-B → อาจหลุด Feeder ทั้งหมด
  • DS Opened/Closed Live (อันตรายมาก): Disconnect ต้อง ไม่ถูกเปิด/ปิดขณะมีไฟ → Arc Flash รุนแรง, อุปกรณ์เสียหาย
  • Grounding Switch Error: ปิด Grounding Switch ขณะมีไฟ → Short Circuit ทันที
  • Backfeed ไม่ถูกตรวจจับ: คิดว่า Bus ดับแล้วแต่ยังมีกระแสย้อน → อันตรายถึงชีวิต
  • Wrong Switching Sequence: ปิด CB ก่อน Disconnect, เปิด Bus Tie ผิดเวลา

SBO Interlocking Conditions Check

เมื่อผู้ปฏิบัติงานกด Select ระบบจะตรวจสอบ:

  • Breaker อยู่ในสถานะที่อนุญาต
  • Disconnect (DS) อยู่ตำแหน่งที่ถูกต้อง
  • Grounding Switch ต้องเปิด (OPEN)
  • ไม่มีการจ่ายไฟย้อน (no backfeed)
  • ไม่มีแรงดันตกค้าง
  • ไม่มีคำสั่งอื่นที่ Active อยู่
  • ไม่มี Local Control Override (Local Switch)

ถ้าเงื่อนไขใดไม่ผ่าน → Select ไม่สำเร็จ → คำสั่งไม่ถูกส่งไปอุปกรณ์จริง

BCU — Bay Control Unit

BCU ทำหน้าที่รับคำสั่ง SBO จาก SCADA, ตรวจสอบ Interlock ที่ Bay Level และส่งคำสั่งไปยังอุปกรณ์จริงใน Substation
